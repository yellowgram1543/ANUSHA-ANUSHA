Built a browser extension that improves safety while interacting with Large Language Models (LLMs) such as ChatGPT, Gemini, and Claude. Detects unsafe or harmful text in prompt boxes before submission to avoid policy violations. Uses a pre-trained ML model with a matching tokenizer for local analysis (privacy-first, low latency).

  • Real-time monitoring of AI prompt boxes
  • Local ML inference using ONNX Runtime Web / Transformers.js
  • Custom rule matching and PII regex checks
  • Low overhead and near-zero latency
  • Customizable sensitivity levels
