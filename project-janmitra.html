Built a full-stack digital governance platform designed to improve accessibility, transparency, and efficiency in public service delivery. Allows users to apply for certificates (Income, Caste, Birth, etc.), track applications via Aadhaar, discover welfare schemes, and report corruption issues.

  • End-to-end certificate applications
  • Real-time application tracking
  • Personalized scheme recommendations
  • Secure document access and storage
  • Corruption reporting mechanism
