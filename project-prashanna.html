Developed a fully responsive, hacker-themed, Multilingual Retrieval-Augmented Generation (RAG) web application. It allows users to ask questions via voice or text, retrieves relevant context from a local FAISS vector store, and generates grounded, context-aware answers.

  • End-to-end RAG platform processing voice and text inputs
  • High-speed local vector search using FAISS and sentence-transformers
  • Exact document context generation effectively eliminating AI hallucinations
  • Sarvam AI and Groq API integrations for real-time semantic translation
  • Native browser Text-to-Speech (TTS) supporting 4 Indic languages
  • Automated Markdown rendering and state-driven frontend
