Developed a comprehensive management portal to streamline trekking packages, assign staff, and enable secure user bookings. Features include an admin dashboard with dynamic Chart.js statistics, role-based access for staff to manage trip statuses, and a secure user booking workflow with safety data capturing.

  • Admin statistics dashboard with dynamic charts
  • Role-based access controls for staff
  • Role-based user portals
  • Automated booking validation flow
  • Safety data capturing workflow
